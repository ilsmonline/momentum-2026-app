The app only displays a View Ad control when the matching asset successfully loads, so missing ads do not become broken public links. If a file uses a different filename, edit the `partnerData` entry in `index.html` to match.

**Upload via GitHub:** Add file → Upload files → Commit changes. Large PNG ads can be optimized for phones first (e.g., max width 1200 px) without destroying your original source assets.

**Do not publish** internal exhibitor details, private forms, contact addresses, payments, or submission data.
