## Photoshop batch export on Windows

1. Open Photoshop, choose **File → Scripts → Image Processor**.
2. Select the source folder: `06-MOMENTUM/2026 Momentum/00 Digital Booklet/Breakout Photos`.
3. Choose **Select Folder** under the destination option and select a **new folder**, not your originals.
4. Check **Save as JPEG**; set **Quality: 7**, enable **Resize to Fit: 700 × 700**, and **Convert Profile to sRGB** if available.
5. Click **Run**. Photoshop outputs JPEG files. Upload those 13 files here with **Add file → Upload files → Commit changes**. There is no need to rename the files; keep their original base names.
