# Momentum 2026 Conference Companion

Mobile-first conference program for November 20–21, 2026, BOS Center, Springfield, Illinois.

## Preview status

`index.html` is a **working preview**, not approved for public release. The Friday/Saturday attendee schedule, breakouts directory, saved sessions, welcome letter, reception details and navigation are included. Final venue maps, verified speaker/session descriptions, public reserved-seating assignments, sponsor profiles, media assets and approved external links still need to be added.

## GitHub Pages

In repository **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.

After GitHub finishes deployment, preview at https://ilsmonline.github.io/momentum-2026-app/ . This URL will only work after Pages has actually been enabled and deployed.
