# Momentum 2026 Conference Companion

Mobile-friendly event companion for Momentum Youth Conference, November 20–21, 2026, at the BOS Center in Springfield, Illinois.

The public companion includes attendee schedules, breakout sessions, venue directions, reserved seating lookup, Spanish interpretation access, and event information.

**Open the companion:** https://ilsmonline.github.io/momentum-2026-app/

This repository contains public-facing event materials only. Internal working documents, production schedules, administrative records, contact information, security plans, and private source-file links must not be added to this repository.
